# Meghna Meme Web 🚀

A fun, interactive prank website featuring floating meme stickers and a very tempting central button.

## 🎯 Features
- **Central Prank Button**: Switches state and plays a sound on click.
- **DVD Bouncing Stickers**: Randomly spawning stickers (with a high frequency of Angry Bird!) that bounce around the screen.
- **Responsive Design**: Works perfectly on both desktop and mobile devices.
- **Clean UI**: Minimalist white background with focus on interactivity.
- **SEO Optimized**: Includes proper title and meta descriptions.

## 🛠️ Tech Stack
- **React**: Frontend framework.
- **Vite**: Ultra-fast build tool.
- **CSS3**: Vanilla CSS for animations and layout.
- **HTML5 Audio**: For sound effects.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- npm (comes with Node.js)

### Installation
1. Clone the repository (or download the source).
2. Open your terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally
To start the development server:
```bash
npm run dev
```
The app will be available at `http://localhost:5173`.

### Building for Production
To create a production build:
```bash
npm run build
```
The optimized files will be generated in the `dist/` directory.

## 📁 Project Structure
- `public/assets/`: Contains images and audio files.
- `src/App.jsx`: Main logic for button state and sticker management.
- `src/index.css`: Global styles and animations.
- `src/main.jsx`: Entry point for React.
